# NovaNest – Responsive Landing Page

A modern, responsive landing page built using React and CSS as part of SkillCraft Technology Web Development Task 01.

## Features

- Responsive design for desktop and mobile devices
- Interactive navigation bar
- Active navbar link highlighting
- Smooth scrolling between sections
- Mobile navigation menu
- Hero, About, Services, Projects, and Contact sections
- Modern UI with hover effects and animations

## Technologies Used

- React
- JavaScript
- CSS
- Vite

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/Yash-K28/SCT_WD_1.git
```

### 2. Open the project folder

```bash
cd SCT_WD_1
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Open the local URL displayed in your terminal to view the website.

## Project Purpose

This project was developed to practice frontend web development, responsive layouts, React components, and interactive navigation.
